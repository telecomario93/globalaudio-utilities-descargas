# Global Audio Utilities — downloads

Basic sound-system calculations, by **Global Audio Solutions**: front fill, subwoofer
arrays, limiters, soundcheck vs show, room acoustics and everyday tools.

This repository only holds the installers. Get the latest version from
**[Releases](../../releases/latest)**.

| System | File |
|---|---|
| Windows 10/11 | `Global Audio Utilities Windows.zip` |
| macOS, Apple Silicon (M1 and later) | `Global Audio Utilities macOS Apple Silicon.zip` |
| macOS, Intel | `Global Audio Utilities macOS Intel.zip` |

## Install

**Windows.** Unzip and run `Global Audio Utilities.exe`. The first time, SmartScreen
may say it does not know the publisher: *More info* → *Run anyway*.

**macOS.** Unzip and move `Global Audio Utilities.app` to *Applications*. The app is not
notarized yet, so the first time macOS blocks it. Open *Terminal* and run:

```
xattr -dr com.apple.quarantine "/Applications/Global Audio Utilities.app"
```

## Descarga e instalación (español)

Descarga la última versión en **[Releases](../../releases/latest)**: el zip de Windows o
el de Mac que corresponda a tu equipo (Apple Silicon o Intel).

- **Windows**: descomprime y abre `Global Audio Utilities.exe`. Si SmartScreen avisa,
  *Más información* → *Ejecutar de todas formas*.
- **Mac**: descomprime, mueve la app a *Aplicaciones* y, la primera vez, en el Terminal:
  `xattr -dr com.apple.quarantine "/Applications/Global Audio Utilities.app"`
